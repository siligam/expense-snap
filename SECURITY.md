# Security Policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report them privately via [GitHub's private vulnerability reporting](https://github.com/siligam/expense-snap/security/advisories/new) or by emailing the maintainer directly.

Include as much detail as possible: steps to reproduce, potential impact, and any suggested fixes.

You can expect an acknowledgement within 48 hours and a fix or mitigation plan within 14 days.
